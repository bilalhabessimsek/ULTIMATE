# 🚀 ULTIMATE - Geliştirici Asistanı & Medya İstasyonu

![Tauri](https://img.shields.io/badge/Tauri-24C8DB?style=for-the-badge&logo=tauri&logoColor=white)
![Rust](https://img.shields.io/badge/Rust-000000?style=for-the-badge&logo=rust&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)
![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge&logo=typescript&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)

**ULTIMATE**, geliştiricilerin günlük iş akışlarını hızlandırmak ve multimedya ihtiyaçlarını tek bir merkezden yönetmek için tasarlanmış, **Tauri ve Rust** tabanlı yüksek performanslı bir masaüstü (Desktop) uygulamasıdır[cite: 3]. 

Sistem kaynaklarını minimum düzeyde tüketirken; akıllı müzik çalar, proje başlatıcı stüdyo, GitHub destekli ATS CV oluşturucu ve Rainmeter entegreli not defteri modüllerini modern bir arayüzde sunar[cite: 3].

### 🎵 1. Akıllı Medya Oynatıcı (Player)

* **Gelişmiş Kuyruk Yönetimi:** Şarkıları sıraya alma, yukarı/aşağı taşıma, sıranın en üstüne sabitleme (Pin) ve özel listeler (Playlist) oluşturma[cite: 3].
* **Sürükle-Bırak:** Yerel klasörleri tarayıp arşivi oluşturduktan sonra şarkıları sürükleyerek çalma listelerine ekleme[cite: 3].

### ☁️ 5. Bulut Senkronu (Supabase)
* **Hesaba Bağlı Güvenlik:** Giriş e-posta + şifre ile yapılır; tüm tablolar **RLS** ile korunur (`auth.uid() = user_id`). Uygulamanın içindeki publishable key'i ele geçiren biri, senin hesabına giriş yapmadıkça verilerine erişemez.
* **Anlık Yedekleme:** Notlar `Ctrl+S` ile hem yerel dosyaya hem **Supabase** `notes` tablosuna yazılır.
* **Takvim Senkronu:** Takvim etkinlikleri `calendar_events` tablosunda tutulur; uygulama ilk açılışta yereldeki (`localStorage`) eski etkinlikleri otomatik olarak buluta taşır.
* **Müzik Senkronu:** Çalma listeleri (`playlists`), favoriler ve dinleme sayıları (`music_state`) bulutta tutulur; başka bir cihazda aynı liste ve favoriler hazır gelir.
* **Kararlı Şarkı Kimlikleri:** Şarkıların kimliği taranan kök klasöre göre göreli yoldur (ör. `rock/parca.mp3`). Böylece müzik klasörü yeniden tarandığında favori ve listeler **yanlış şarkıya işaret etmez**; klasör hatırlanır ve açılışta otomatik taranır.
* **Realtime:** Aynı hesaptan açılan diğer pencereler/cihazlar, veritabanı olaylarını (**INSERT/UPDATE/DELETE**) kanal üzerinden dinleyerek listeleri anında günceller.
* **Offline-first:** Bağlantı yoksa uygulama `localStorage`'a düşer; takvim başlığında küçük bir "yerel" rozeti görünür ve kullanım kesintisiz devam eder.
* **Şema:** Tüm tablolar, RLS politikaları ve realtime ayarları `supabase/schema.sql` dosyasındadır.

## 🚀 Kurulum ve Çalıştırma

Projeyi kendi bilgisayarınızda çalıştırmak veya derlemek için Node.js ve Rust (Cargo) ortamlarının kurulu olması gerekmektedir[cite: 3].

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/bilalhabessimsek/ULTIMATE.git
   cd ULTIMATE
   ```

2. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```

3. Ortam değişkenlerini ayarlayın:
   ```bash
   cp .env.example .env
   ```
   `.env` içine Supabase **Project URL** ve **Publishable key**'ini girin (aşağıya bakın).

4. Geliştirme modunda çalıştırın:
   ```bash
   npm run tauri dev
   ```

5. Üretim derlemesi (Windows `.msi` / `.exe` dahil):
   ```bash
   npm run tauri build
   ```

## ☁️ Supabase Kurulumu (Bulut Senkronu)

Notların bulutta senkronize olması için tek seferlik kurulum gerekir:

1. [supabase.com/dashboard](https://supabase.com/dashboard) adresinden projenizi açın.
2. Proje ana sayfasındaki **`Connect`** butonuna tıklayın → **Project URL** ve **Publishable key**'i kopyalayın.
3. Kopyaladıklarınızı `.env` dosyasına yazın:
   ```env
   VITE_SUPABASE_URL=https://<20-haneli-proje-ref>.supabase.co
   VITE_SUPABASE_ANON_KEY=sb_publishable_...
   ```
   > ⚠️ **Project URL'deki ref'i birebir kopyalayın.** Tek bir harf hatası (ör. `g` ↔ `q`) DNS kaydını tamamen kırar ve hata "DNS adı yok" olarak görünür.

4. **Tablolar + politikalar + realtime:** `supabase/schema.sql` dosyasının **tamamını** SQL editöründe çalıştırın. Script;
   - `notes`, `calendar_events`, `playlists`, `music_state` tablolarını,
   - **hesaba bağlı** RLS politikalarını (`auth.uid() = user_id`),
   - not resimleri için **`note-images` Storage bucket'ını** ve yazma/silme politikalarını (9. bölüm),
   - realtime yayın üyeliğini
   
   tek seferde kurar. Ayrıca 7. bölümü sahipsiz eski satırları ilk kullanıcıya bağlar ve bileşik anahtarları (`user_id + name/key`) oluşturur.

   > ⚠️ Önce **Authentication → Users** ekranından bir kullanıcı oluşturun. Kullanıcı yoksa script uyarı verip durur (bilinçli koruma).
   > ⚠️ Elle **`using (true)` politikası eklemeyin.** Postgres politikaları varsayılan olarak **VEYA** ile birleşir; tek bir gevşek politika tüm RLS korumasını geçersiz kılar.

**Hızlı doğrulama (terminal):**
```bash
curl -s -H "apikey: $VITE_SUPABASE_ANON_KEY" \
  "https://<proje-ref>.supabase.co/rest/v1/notes?select=id&limit=1"
```
Oturum açılmadığı için `[]` dönmesi **beklenen** davranıştır (RLS veriyi kapatıyor). Yazma denemesi `42501` ile reddedilmeli.

### 🖼️ Not Resimleri (Supabase Storage)

Notlara eklenen resimler artık **base64 olarak veritabanına gömülmez**. Resim Supabase Storage'daki `note-images` bucket'ına yüklenir, nota yalnızca kısa bir genel URL yazılır.

**Neden?** Base64 gömme resmi ~%33 şişirir ve `notes.content` kolonunu megabaytlara çıkarır; ayrıca resim yalnızca o bilgisayarda kalırdı. Storage ile veritabanı küçük kalır ve resim **tüm cihazlarda** görünür.

Üç yolla resim eklenebilir:

| Yöntem | Nasıl |
|---|---|
| **Buton** | Araç çubuğundaki 🖼️ ikonu → dosya seçici |
| **Yapıştır** | Ekran görüntüsünü kopyala → editörde **Ctrl+V** |
| **Sürükle-bırak** | Resim dosyasını editörün üzerine bırak |

Yükleme sırasında araç çubuğunda "Resim yükleniyor..." göstergesi çıkar; hata olursa kırmızı bir uyarı bandı görünür.

**Kurulum:** `supabase/schema.sql` **9. bölümünü** (bucket + politikalar) bir kez çalıştırmak yeterlidir — dosyanın tamamını çalıştırdıysanız zaten kurulmuştur. Bucket'ı Dashboard'dan elle de açabilirsiniz:

1. **Storage → New bucket** → ad: **`note-images`** → **Public bucket** açık → *Create*.
2. **Policies** için yukarıdaki SQL'i çalıştırın (yazma/silme yalnızca kendi `<user_id>/` klasörüne izinlidir).

> 🔒 Bucket **public** olduğu için bağlantıyı bilen resmi görüntüleyebilir (URL'ler rastgele ve tahmin edilemez). Kişisel kullanım için pratiktir; tam gizlilik istersen bucket'ı private yapıp imzalı URL üretimine geçebiliriz.
> 📦 Ücretsiz plan Storage kotası 1 GB'dır. Tek resim üst sınırı uygulama tarafında **10 MB**.

## 🔐 Kimlik Doğrulama (Auth)

Notlar, takvim ve listeler artık **hesaba bağlı**. Satır Düzeyi Güvenlik (RLS) politikaları `auth.uid() = user_id` şeklinde olduğu için publishable key'e sahip başka biri **kendi hesabı olmadan verilerini göremez**.

Kurulum sırası önemli:

1. Dashboard → **Authentication → Users** → *Add user* → e-posta + şifre gir, **Auto Confirm** işaretli olsun.
2. `supabase/schema.sql` dosyasının tamamını SQL editöründe çalıştır (7. bölüm sahipsiz eski satırları otomatik olarak bu kullanıcıya bağlar).
3. Uygulamayı aç → giriş ekranı gelir → aynı e-posta/şifre ile giriş yap.

> E-posta onayı zorunlu olsun istemiyorsan: Authentication → Sign In / Providers → Email → **Confirm email** kapalı olabilir. Kapalıysa hesap oluşturur oluşturmaz giriş yapılır.

Oturum yerelde saklandığı için uygulama her açılışta tekrar giriş istemez; çıkış için sol menüdeki **çıkış (LogOut)** butonu kullanılır.

### 🔁 Şifre Sıfırlama (bağlantı yapıştırma)

Masaüstü uygulamasında e-posta bâglantısına tıklamak işe yaramaz (tarayıcıya `http://localhost:3000`'e gider). Bu yüzden uygulama, e-postadaki bağlantının **içindeki token**'ı okur:

1. Giriş ekranı → **Şifremi unuttum** → e-postanı gir → *Sıfırlama Bağlantısı Gönder*.
2. Gelen e-postada **"Reset password"** yazısına sağ tık → **Bağlantıyı kopyala**.
3. Uygulamadaki kutuya yapıştır + yeni şifreyi belirle → *Şifreyi Güncelle*.

Uygulama yapıştırılan metinden `token=` değerini ayıklar ve `supabase.auth.verifyOtp({ token_hash, type: 'recovery' })` ile oturumu açar, ardından şifreyi günceller.

> **Neden kod (OTP) değil?** 6 haneli kod yöntemi e-posta şablonuna `{{ .Token }}` eklemeyi gerektirir; ancak Supabase ücretsiz planında **varsayılan mail servisi kullanılırken şablon düzenlenemez** (custom SMTP veya Pro plan gerekir). Bağlantı yapıştırma yöntemi hiçbir ayar gerektirmez ve varsayılan şablonla çalışır.
>
> Kod alanı da desteklenir: e-postada 6 haneli kod varsa (custom SMTP + `{{ .Token }}` şablonu kuruluysa) doğrudan o kod girilebilir.
> Bağlantının geçerlilik süresi: Authentication → Providers → Email → *Email OTP Expiry* (varsayılan 3600 sn).

  const [recoveryBusy, setRecoveryBusy] = useState(false)

  useEffect(() => {
    supabase.auth.getSession().then(({ data }) => {
      setSession(data.session)
      setAuthReady(true)
    })

    const { data: authListener } = supabase.auth.onAuthStateChange((_event, newSession) => {
      setSession(newSession)
    })

    return () => authListener.subscription.unsubscribe()
  }, [])

  const handleSignOut = async () => {
    if (!confirm('Oturumu kapatmak istediğine emin misin? (Veriler hesabında güvende kalır)')) return
    await supabase.auth.signOut()
  }

  // Oturum değişince yerel depolamayı o hesaba göre hazırla.
  // Eski (hesap öneki olmayan) veriler yalnızca bulutunda verisi olan
  // "kurulu" hesaba devredilir; yeni/boş bir hesap onları sahiplenemez.
  useEffect(() => {
    if (!authReady) return
    let cancelled = false

    const prepareStorage = async () => {
      if (!session) {
        setCurrentUserId(null)
        setStorageReady(true)
        return
      }

      setStorageReady(false)
      setCurrentUserId(session.user.id)

      if (hasLegacyKeys()) {
        try {
          const { count } = await supabase
            .from('notes')
            .select('id', { count: 'exact', head: true })

          if (cancelled) return

          if ((count ?? 0) > 0) {

          }
        } catch (err) {
          console.error('Yerel veri devri kontrolü başarısız:', err)
        }

      if (!cancelled) setStorageReady(true)
    }

    prepareStorage()

    return () => {
      cancelled = true
    }
  }, [session, authReady])

  if (!authReady || (session && !storageReady && !recoveryBusy)) {

      <div className="flex h-screen w-full items-center justify-center bg-background text-sm text-muted-foreground">

    )
  }

  // böylece yetkisiz sorgu ve realtime aboneliği oluşmaz.

  // giriş ekranında kalınır; yeni şifre kaydedilip mesaj gösterilir.
  if (!session || recoveryBusy) {
    return <LoginView onRecoveryBusyChange={setRecoveryBusy} />
  }

  return (
    <div className="flex h-screen w-full overflow-hidden bg-background text-foreground">
      <DesktopSidebar

}

/**
 * Hesap bazlı yerel depolama.
 *
 * Sorun: Notlar, takvim ve müzik verileri `localStorage`'ta hesaptan bağımsız
 * (öneksiz) tutuluyordu. Aynı bilgisayarda farklı bir hesapla giriş yapıldığında
 * önceki hesabın verileri ekranda görünüyor ve üstelik yeni hesabın bulutuna
 * yazılabiliyordu.
 *
 * Çözüm: Bulutla senkronize edilen tüm anahtarlar `user:<kullanici-id>:<anahtar>`
 * biçiminde saklanır. Böylece her hesap yalnızca kendi yerel önbelleğini görür.
 *
 * Cihaza özel ayarlar (müzik klasörü yolu, sıralama tercihi, Rainmeter yolu,
 * proje klasörleri, CV bilgileri, ilk kurulum bayrağı) bilinçli olarak global
 * bırakılmıştır; bunlar veri değil, makine yapılandırmasıdır.
 */

let currentUserId: string | null = null

/** Giriş/çıkış anında App tarafından çağrılır. */
export function setCurrentUserId(id: string | null): void {
  currentUserId = id
}

export function getActiveUserId(): string | null {
  return currentUserId
}

function prefix(): string {
  return currentUserId ? `user:${currentUserId}:` : 'user:anon:'
}

export function uGet(key: string): string | null {
  try {
    return localStorage.getItem(prefix() + key)
  } catch {
    return null
  }
}

export function uSet(key: string, value: string): void {
  try {
    localStorage.setItem(prefix() + key, value)
  } catch (err) {
    console.error('Yerel kayıt hatası:', err)
  }
}

export function uRemove(key: string): void {
  try {
    localStorage.removeItem(prefix() + key)
  } catch {
    /* yoksay */
  }
}

export function uGetJson<T>(key: string, fallback: T): T {
  const raw = uGet(key)
  if (raw === null) return fallback
  try {
    return JSON.parse(raw) as T
  } catch {
    return fallback
  }
}

export function uSetJson(key: string, value: unknown): void {
  uSet(key, JSON.stringify(value))
}

/**
 * Bulutla senkronize edilen anahtarlar. Bunlar hesap bazlı olmalıdır.
 */
export const SYNCED_KEYS = [
  'ultimate_notes',
  'ultimate_events',
  'music_favs',
  'music_playlists',
  'music_playcounts',
  'music_ids_migrated_v2',
  'music_cloud_migrated_v2',
] as const

/** Eski (hesap öneki olmayan) yerel veri duruyor mu? */
export function hasLegacyKeys(): boolean {
  for (const key of SYNCED_KEYS) {
    try {
      if (localStorage.getItem(key) !== null) return true
    } catch {
      /* yoksay */
    }
  }
  return false
}

/**
 * Eski (öneksiz) yerel veriyi aktif hesaba devreder ve öneksiz kopyaları siler.
 *
 * Sadece "kurulu" hesap için çağrılmalıdır (bulutunda verisi olan hesap).
 * Aksi halde yeni açılmış boş bir hesap, başka bir hesabın verisini sahiplenirdi.
 */
export function claimLegacyKeys(): void {
  for (const key of SYNCED_KEYS) {
    let legacy: string | null = null
    try {
      legacy = localStorage.getItem(key)
    } catch {
      continue
    }
    if (legacy === null) continue

    if (uGet(key) === null) uSet(key, legacy)
    try {
      localStorage.removeItem(key)
    } catch {
      /* yoksay */
    }
  }
}

  const readLocalCache = (): EventItem[] => {
    try {
      const saved = uGet('ultimate_events')
      if (!saved) return []
      const parsed = JSON.parse(saved) as Record<string, string[]>
      let tempId = -1
      return Object.entries(parsed).flatMap(([date, titles]) =>
        (titles || []).map((title) => ({ id: tempId--, date, title }))

import { useState } from 'react'
import { Command, Lock, Mail, Loader2, ShieldCheck, KeyRound, ArrowLeft } from 'lucide-react'
import { supabase } from '../lib/supabase'

// 'reset'        : e-posta girilir, sifirlama kodu istenir
// 'resetConfirm' : gelen 6 haneli kod + yeni sifre girilir
type Mode = 'login' | 'signup' | 'reset' | 'resetConfirm'

interface LoginViewProps {
  /**
   * Sifre sifirlama sirasinda true olur. App bu bayrak acikken ana ekrana
   * gecmez; boylece kod dogrulandiktan sonra sifre guncellenip mesaj
   * gosterilebilir (oturum hemen acilsa bile ekran degismez).
   */
  onRecoveryBusyChange?: (busy: boolean) => void
}

export function LoginView({ onRecoveryBusyChange }: LoginViewProps) {
  const [mode, setMode] = useState<Mode>('login')
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [recoveryInput, setRecoveryInput] = useState('')
  const [newPassword, setNewPassword] = useState('')
  const [newPassword2, setNewPassword2] = useState('')
  const [isLoading, setIsLoading] = useState(false)
  const [error, setError] = useState<string | null>(null)
  const [info, setInfo] = useState<string | null>(null)

  const goTo = (next: Mode) => {
    setMode(next)
    setError(null)
    setInfo(null)
  }

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault()
    setError(null)
    setInfo(null)

    if (!email.trim() || !password) {
      setError('E-posta ve şifre gerekli.')
      return
    }

    setIsLoading(true)
    try {
      if (mode === 'login') {
        const { error } = await supabase.auth.signInWithPassword({
          email: email.trim(),
          password,
        })
        if (error) throw error
      } else {
        const { data, error } = await supabase.auth.signUp({
          email: email.trim(),
          password,
        })
        if (error) throw error

        // E-posta onayı açıksa oturum hemen açılmaz
        if (!data.session) {
          setInfo('Hesap oluşturuldu. E-postana gelen onay bağlantısına tıkladıktan sonra giriş yapabilirsin.')
          setMode('login')
        }
      }
    } catch (err: any) {
      const message: string = err?.message || 'Bilinmeyen bir hata oluştu.'
      if (message.toLowerCase().includes('invalid login credentials')) {
        setError('E-posta veya şifre hatalı.')
      } else if (message.toLowerCase().includes('email not confirmed')) {
        setError('E-posta adresin henüz onaylanmamış. Gelen kutunu kontrol et.')
      } else {
        setError(message)
      }
    } finally {
      setIsLoading(false)
    }
  }

  // 1. adım: sifirlama kodu iste
  const requestResetCode = async () => {
    setError(null)
    setInfo(null)

    const mail = email.trim()
    if (!mail) {
      setError('E-posta adresini gir.')
      return
    }

    setIsLoading(true)
    try {
      const { error } = await supabase.auth.resetPasswordForEmail(mail)
      if (error) throw error

      setRecoveryInput('')
      setNewPassword('')
      setNewPassword2('')
      setMode('resetConfirm')
      setInfo('E-postana sıfırlama bağlantısı gönderdik. Bağlantıyı kopyalayıp aşağıya yapıştır (6 haneli kod da geçerlidir).')
    } catch (err: any) {
      const message: string = err?.message || 'Kod gönderilemedi.'
      if (message.toLowerCase().includes('rate limit') || message.toLowerCase().includes('too many')) {
        setError('Çok fazla kod istedin. Birkaç dakika bekleyip tekrar dene.')
      } else {
        setError(message)
      }
    } finally {
      setIsLoading(false)
    }
  }

  const handleResetRequest = (e: React.FormEvent) => {
    e.preventDefault()
    void requestResetCode()
  }

  // E-postadaki baglantidan token_hash'i (veya 6 haneli kodu) cikarir
  const parseRecoveryInput = (raw: string): { token?: string; tokenHash?: string } | null => {
    const text = raw.trim()
    if (!text) return null

    // 1) 6 haneli kod (bosluk/tire ile yazilmis olabilir)
    const digitsOnly = text.replace(/[\s-]/g, '')
    if (/^\d{6}$/.test(digitsOnly)) return { token: digitsOnly }

    // 2) Baglantidan token_hash cikar: ...?token=... veya ?token_hash=...
    const fromUrl = text.match(/[?&]token(?:_hash)?=([A-Za-z0-9._\-]+)/)
    if (fromUrl) return { tokenHash: fromUrl[1] }

    // 3) Dogrudan token_hash yapistirilmis olabilir
    if (/^[A-Za-z0-9._\-]{20,}$/.test(text)) return { tokenHash: text }

    return null
  }

  // 2. adım: kodu dogrula + yeni sifreyi kaydet
  const handleResetConfirm = async (e: React.FormEvent) => {
    e.preventDefault()
    setError(null)
    setInfo(null)

    const mail = email.trim()
    const parsed = parseRecoveryInput(recoveryInput)
    if (!parsed) {
      setError('E-postadaki sıfırlama bağlantısını yapıştır ya da 6 haneli kodu gir.')
      return
    }
    if (parsed.token && !mail) {
      setError('E-posta adresi eksik. Baştan başla.')
      return
    }
    if (newPassword.length < 6) {
      setError('Yeni şifre en az 6 karakter olmalı.')
      return
    }
    if (newPassword !== newPassword2) {
      setError('İki şifre birbiriyle uyuşmuyor.')
      return
    }

    setIsLoading(true)
    // Kod dogrulaninca oturum acilir; App'in ana ekrana gecmemesi icin kilit
    onRecoveryBusyChange?.(true)
    let completed = false
    try {
      const { error } = parsed.tokenHash
        ? await supabase.auth.verifyOtp({ token_hash: parsed.tokenHash, type: 'recovery' })
        : await supabase.auth.verifyOtp({ email: mail, token: parsed.token!, type: 'recovery' })
      if (error) throw error

      const { error: updateError } = await supabase.auth.updateUser({ password: newPassword })
      if (updateError) throw updateError

      completed = true
      setInfo('Şifren güncellendi! Uygulama açılıyor...')

    } catch (err: any) {

        await supabase.auth.signOut()
      } catch {
        /* yoksay */

      onRecoveryBusyChange?.(false)

      const message: string = err?.message || 'Doğrulanamadı.'
      const lower = message.toLowerCase()
      if (lower.includes('expired') || lower.includes('invalid') || lower.includes('token')) {

    } finally {

  }

  const isResetMode = mode === 'reset' || mode === 'resetConfirm'

type Note = {

  pinned: boolean
}

/** Not resimlerinin yüklendiği Supabase Storage bucket'ı (supabase/schema.sql, 9. bölüm) */
const NOTE_IMAGES_BUCKET = 'note-images'
/** Tek resim için üst sınır (MB) - Storage kotasını korur */
const MAX_IMAGE_MB = 10

export function NotesView() {
  const [notes, setNotes] = useState<Note[]>([])
  const [activeId, setActiveId] = useState<string | null>(null)
  const [searchQuery, setSearchQuery] = useState('')
  const [isSaving, setIsSaving] = useState(false)
  const [rainmeterPath, setRainmeterPath] = useState<string | null>(null)
  const [isUploadingImage, setIsUploadingImage] = useState(false)
  const [uploadError, setUploadError] = useState<string | null>(null)

  const fetchNotes = async () => {
    try {
      const { data, error } = await supabase
        .from('notes')
        .select('id, title, content, tag, pinned, updated_at')
        .order('pinned', { ascending: false })
        .order('updated_at', { ascending: false })

      if (error) throw error

      if (data && data.length > 0) {
        const fetchedNotes: Note[] = data.map((note: any) => ({
          id: note.id,
          title: note.title || '',
          content: note.content || '',
          tag: note.tag || 'genel',
          pinned: note.pinned || false,
          updatedAt: note.updated_at
        }))
        setNotes(fetchedNotes)
        if (!activeId) {
          setActiveId(fetchedNotes[0].id)
        }
      } else {
        const welcomeNote: Note = {
          id: Date.now().toString(),
          title: 'İlk Notum 📌',

          updatedAt: Date.now(),
          tag: 'sistem',
          pinned: true

        setNotes([welcomeNote])
        setActiveId(welcomeNote.id)
      }
    } catch (err) {
      console.error('Supabase fetch error:', err)
      const savedNotes = uGet('ultimate_notes')
      if (savedNotes) {
        const parsed = JSON.parse(savedNotes)
        setNotes(parsed)
        if (parsed.length > 0 && !activeId) setActiveId(parsed[0].id)
      }
    }
  }

  useEffect(() => {
    const savedRainmeter = localStorage.getItem('rainmeter_path')
    if (savedRainmeter) setRainmeterPath(savedRainmeter)
    fetchNotes()

    const channel = supabase
      .channel('notes-realtime')
      .on(
        'postgres_changes',
        { event: '*', schema: 'public', table: 'notes' },
        () => {
          fetchNotes()
        }
      )
      .subscribe()

    return () => {
      supabase.removeChannel(channel)
    }
  }, [])

  const activeNote = notes.find(n => n.id === activeId)

  // ------------------------------------------------------------------
  // NOT RESİMLERİ: Supabase Storage'a yükleme
  // Resimler artık base64 olarak not içeriğine gömülmez; Storage'a yüklenir

  // ------------------------------------------------------------------
  const uploadImageRef = useRef<(file: File, pos?: number) => Promise<void>>(async () => {})

  const uploadNoteImage = async (file: File): Promise<string> => {
    const userId = getActiveUserId() ?? (await supabase.auth.getUser()).data.user?.id
    if (!userId) throw new Error('Oturum bulunamadı, tekrar giriş yap.')

    const ext = (file.name.split('.').pop() || 'png').toLowerCase().replace(/[^a-z0-9]/g, '') || 'png'
    const path = `${userId}/${Date.now()}_${Math.random().toString(36).slice(2, 10)}.${ext}`

    const { error } = await supabase.storage
      .from(NOTE_IMAGES_BUCKET)
      .upload(path, file, {
        cacheControl: '31536000',
        contentType: file.type || 'image/png',
        upsert: false,
      })
    if (error) throw error

    const { data } = supabase.storage.from(NOTE_IMAGES_BUCKET).getPublicUrl(path)
    if (!data?.publicUrl) throw new Error('Genel bağlantı alınamadı.')
    return data.publicUrl
  }

  // Resmi yükleyip imlecin olduğu yere (veya mevcut konuma) ekler
  const uploadAndInsertImage = async (file: File, pos?: number) => {
    if (!editor) return
    if (!file.type.startsWith('image/')) return
    if (file.size > MAX_IMAGE_MB * 1024 * 1024) {
      setUploadError(`Resim çok büyük (en fazla ${MAX_IMAGE_MB} MB).`)
      return
    }

    setUploadError(null)
    setIsUploadingImage(true)
    try {
      const url = await uploadNoteImage(file)
      if (typeof pos === 'number') {
        editor.chain().focus().insertContentAt(pos, { type: 'image', attrs: { src: url } }).run()
      } else {
        editor.chain().focus().setImage({ src: url }).run()
      }
    } catch (err: any) {
      console.error('Resim yükleme hatası:', err)
      const msg: string = err?.message || 'bilinmeyen hata'
      setUploadError(
        msg.toLowerCase().includes('bucket')
          ? 'Storage bucket bulunamadı. supabase/schema.sql 9. bölümü çalıştır.'
          : 'Resim yüklenemedi: ' + msg,
      )
    } finally {
      setIsUploadingImage(false)
    }
  }

  // Editör olayları (paste/drop) için her zaman güncel fonksiyona erişim
  useEffect(() => {
    uploadImageRef.current = (file: File, pos?: number) => uploadAndInsertImage(file, pos)
  })

  // TIPTAP EDİTÖR KURULUMU

    extensions: [

      // allowBase64: true -> ESKİ notlardaki gömülü (base64) resimler görünmeye

      Image.configure({ inline: true, allowBase64: true }),
      Placeholder.configure({ placeholder: 'Aklındakileri buraya dök, resimleri doğrudan ekle...' })
    ],
    content: activeNote?.content || '',
    onUpdate: ({ editor }) => {
      // Her harf yazıldığında state'i sessizce günceller
      updateActiveNote('content', editor.getHTML())
    },
    editorProps: {
      // Panodan görsel yapıştırma (ekran görüntüsü dahil)
      handlePaste: (view, event) => {
        const items = event.clipboardData?.items
        if (!items) return false
        for (const item of items) {
          if (item.type.startsWith('image/')) {
            const file = item.getAsFile()
            if (file) {
              event.preventDefault()
              void uploadImageRef.current(file, view.state.selection.from)
              return true
            }
          }
        }
        return false
      },
      // Sürükle-bırak ile görsel ekleme
      handleDrop: (view, event, _slice, moved) => {
        if (moved) return false // editör içinde taşınan içerik
        const files = event.dataTransfer?.files
        if (!files || files.length === 0) return false
        const imageFile = Array.from(files).find(f => f.type.startsWith('image/'))
        if (!imageFile) return false
        event.preventDefault()
        const pos = view.posAtCoords({ left: event.clientX, top: event.clientY })?.pos
        void uploadImageRef.current(imageFile, pos)
        return true
      },
    },
  })

  // Aktif not değiştiğinde editörün içeriğini güvenle yeniler
  useEffect(() => {
    if (editor && activeNote && editor.getHTML() !== activeNote.content) {
      editor.commands.setContent(activeNote.content)
    }
  }, [activeId, editor])

  // Rainmeter Temizleyici (HTML'i güvenli metne çevirir)
  const cleanForRainmeter = (htmlText: string) => {
    if (!htmlText) return "▪ Boş not."
    const tempDiv = document.createElement('div')
    // Resimleri [Resim] tag'ine çevir
    const processedHtml = htmlText.replace(/<img[^>]*>/gi, ' [Resim] ')
    tempDiv.innerHTML = processedHtml
    return tempDiv.innerText.trim() || "▪ Boş not."
  }

  const handleManualSave = async (latestNotes?: Note[]) => {
    const notesToProcess = latestNotes || notes;
    setIsSaving(true)
    uSet('ultimate_notes', JSON.stringify(notesToProcess))

    try {
      for (const note of notesToProcess) {
        const { error } = await supabase.from('notes').upsert({
          id: note.id,
          title: note.title,
          content: note.content,
          tag: note.tag,
          pinned: note.pinned,
          updated_at: note.updatedAt
        })
        if (error) {
          console.error('Supabase upsert error:', error)
        }
      }
    } catch (err) {
      console.error('Supabase save error:', err)
    }

    if (rainmeterPath) {
      const sortedForRainmeter = [...notesToProcess]
        .filter(n => n.pinned)
        .sort((a, b) => b.updatedAt - a.updatedAt)
        .slice(0, 8)
      
      // KUSURSUZ TEMİZLİK: Sadece başlığı (title) alıyoruz, içerik/önizleme kısımlarını tamamen sildik!
      const content = sortedForRainmeter.length > 0 
        ? sortedForRainmeter.map(n => `▪ ${n.title || 'İsimsiz Not'}`).join('\r\n')
        : '▪ Sabitlenmis notunuz bulunmuyor.'
      
      try {
        await invoke('save_txt_file', { path: rainmeterPath, content })
      } catch (err) {
        console.error('Rainmeter Kayıt Hatası:', err)
      }
    }
    setTimeout(() => setIsSaving(false), 1000)
  }

  // BİLGİSAYARDAN RESİM EKLEME (Storage'a yükler, nota yalnızca URL yazar)
  const handleInsertImage = async () => {
    if (!editor) return
    try {
      const selected = await open({
        multiple: false,
        filters: [{ name: 'Resimler', extensions: ['png', 'jpg', 'jpeg', 'gif', 'webp'] }]
      })
      if (!selected || typeof selected !== 'string') return

      const fileName = selected.split(/[\\/]/).pop() || 'resim.png'
      const ext = (fileName.split('.').pop() || 'png').toLowerCase()
      const mime = ext === 'jpg' || ext === 'jpeg' ? 'image/jpeg' : `image/${ext}`

      // Yerel dosyayı byte olarak oku (read_audio_file genel amaçlı dosya okuyucudur)
      const bytes = await invoke<number[]>('read_audio_file', { path: selected })
      const file = new File([new Uint8Array(bytes)], fileName, { type: mime })

    } catch (e: any) {
      console.error(e)
      setUploadError('Resim eklenemedi: ' + (e?.message || e))
    }

    try {
      const selectedPath = await open({ multiple: false, filters: [{ name: 'Metin Belgesi', extensions: ['txt', 'md', 'log'] }] })

        { user_id: userId, key, value, updated_at: new Date().toISOString() },
        { onConflict: 'user_id,key' }
      )
    if (error) console.error('Supabase müzik verisi kaydetme hatası:', error)
  }

  const loadCloudMusicData = async () => {
    try {
      const { data: listRows, error: listError } = await supabase.from('playlists').select('name, track_ids')
      if (listError) throw listError

      const remotePlaylists: Record<string, string[]> = {}
      for (const row of (listRows || []) as { name: string; track_ids: string[] | null }[]) {
        remotePlaylists[row.name] = row.track_ids || []
      }

      if (Object.keys(remotePlaylists).length > 0) {
        setPlaylists(remotePlaylists)
        uSet('music_playlists', JSON.stringify(remotePlaylists))
      }

      const { data: stateRows, error: stateError } = await supabase.from('music_state').select('key, value')
      if (stateError) throw stateError

      const state: Record<string, unknown> = {}
      for (const row of (stateRows || []) as { key: string; value: unknown }[]) {
        state[row.key] = row.value
      }

      if (Array.isArray(state.favorites)) {
        const favs = state.favorites as string[]
        setFavorites(favs)
        uSet('music_favs', JSON.stringify(favs))
      }

      if (state.play_counts && typeof state.play_counts === 'object') {
        const counts = state.play_counts as Record<string, number>
        setPlayCounts(counts)
        uSet('music_playcounts', JSON.stringify(counts))
      }
    } catch (err) {
      console.error('Supabase müzik verisi çekilemedi:', err)
    }
  }

  // Yereldeki müzik verisini buluta bir kez taşır (ilk kurulum göçü).
  // Bulut zaten doluysa yukarıdaki çekme işlemi yereli bulutla eşitlediği için
  // bu göç sadece aynı veriyi tekrar yazmış olur; zararsız.
  const pushLocalMusicDataToCloud = async () => {
    if (uGet('music_cloud_migrated_v2') === 'done') return

    const userId = await getUserId()
    if (!userId) return

    const lists = readLocalJson<Record<string, string[]>>('music_playlists', {})
    const names = Object.keys(lists)
    if (names.length > 0) {
      const { error } = await supabase
        .from('playlists')
        .upsert(
          names.map((name) => ({ user_id: userId, name, track_ids: lists[name], updated_at: new Date().toISOString() })),
          { onConflict: 'user_id,name' }
        )
      if (error) console.error('Playlist göçü hatası:', error)
    }

    const favs = readLocalJson<string[]>('music_favs', [])
    if (favs.length > 0) await pushMusicState('favorites', favs)

    const counts = readLocalJson<Record<string, number>>('music_playcounts', {})
    if (Object.keys(counts).length > 0) await pushMusicState('play_counts', counts)

    // Göç tamamlandı olarak işaretle; aksi halde her klasör taramasında tekrar yükleniyordu.
    uSet('music_cloud_migrated_v2', 'done')
  }

  const stopCurrentTrack = () => {
    if (audioRef.current) {
      audioRef.current.pause()
      audioRef.current.src = ''
    }
    Tone.Transport.stop()
    Tone.Transport.position = 0
    Tone.Transport.cancel()
    synthsRef.current.forEach(s => s.dispose())
    synthsRef.current = []
  }

  const handleScanFolder = async () => {
    try {
      const selectedFolder = await open({ directory: true, multiple: false })
      if (selectedFolder && typeof selectedFolder === 'string') {
        localStorage.setItem('music_folder', selectedFolder)
        await loadTracks(selectedFolder)
      }
    } catch (error) {
      console.error("Hata:", error)
    }
  }

  const playTrack = async (track: Track, queueContext?: Track[], preserveQueue: boolean = false) => {
    setActiveTrack(track)
    setIsPlaying(false)
    stopCurrentTrack()
    
    const activeQueue = queueContext || currentQueueRef.current || displayedTracks
    currentQueueRef.current = activeQueue

    if (!preserveQueue) {
      const idx = activeQueue.findIndex(t => t.id === track.id)
      if (idx !== -1) {
        setQueue(activeQueue.slice(idx + 1).map((t, i) => ({ qid: Date.now() + i, track: t, pinned: false })))
      } else {
        setQueue([])
      }
    }

    const newCounts = { ...playCounts, [track.id]: (playCounts[track.id] || 0) + 1 }
    setPlayCounts(newCounts)
    uSet('music_playcounts', JSON.stringify(newCounts))
    pushMusicState('play_counts', newCounts)

    if ('mediaSession' in navigator) {
      navigator.mediaSession.metadata = new MediaMetadata({ title: track.title, artist: 'Ultimate Oynatıcı' })
    }

    try {
      const bytes = await invoke<number[]>('read_audio_file', { path: track.path })
      const arrayBuffer = new Uint8Array(bytes)

      if (track.format === 'MID' || track.format === 'MIDI') {
        setIsMidi(true)
        const midi = new Midi(arrayBuffer)
        await Tone.start() 
        const synths: Tone.PolySynth[] = []
        midi.tracks.forEach(t => {
          if (t.notes.length > 0) {
            const synth = new Tone.PolySynth(Tone.Synth, { oscillator: { type: "triangle" } }).toDestination()
            synths.push(synth)
            const part = new Tone.Part((time, note) => {
              synth.triggerAttackRelease(note.name, note.duration, time, note.velocity)
            }, t.notes.map(n => ({ time: n.time, name: n.name, duration: n.duration, velocity: n.velocity })))
            part.start(0)
          }
        })
        synthsRef.current = synths
        Tone.Transport.start()
        Tone.Transport.scheduleOnce(() => {
          setIsPlaying(false)
          if (playNextRef.current) playNextRef.current()
        }, `+${midi.duration}`)
        setIsPlaying(true)
      } else {
        setIsMidi(false)
        const blob = new Blob([arrayBuffer], { type: getMimeType(track.format) })
        const url = URL.createObjectURL(blob)
        if (audioRef.current) {
          audioRef.current.src = url
          audioRef.current.volume = volume
          audioRef.current.play()
          setIsPlaying(true)
        }
      }
    } catch (error) {
      console.error("Çalınamadı:", error)
    }
  }

  const togglePlay = () => {
    if (!activeTrack) return
    if (isMidi) {
      if (isPlaying) { Tone.Transport.pause(); setIsPlaying(false) } 
      else { Tone.Transport.start(); setIsPlaying(true) }
    } else {
      if (!audioRef.current) return
      if (isPlaying) { audioRef.current.pause(); setIsPlaying(false) } 
      else { audioRef.current.play(); setIsPlaying(true) }
    }
  }

  const toggleLoop = () => {
    if (loopMode === 'none') setLoopMode('all')
    else if (loopMode === 'all') setLoopMode('one')
    else setLoopMode('none')
  }

  const playNext = () => {
    if (loopMode === 'one' && audioRef.current && activeTrack) {
      audioRef.current.currentTime = 0;
      audioRef.current.play();
      setIsPlaying(true);
      return;
    }

    if (queue.length > 0) {
      let nextItemIdx = 0;
      if (isShuffle) {
        nextItemIdx = Math.floor(Math.random() * queue.length);
      }
      const nextTrack = queue[nextItemIdx].track;
      setQueue(prev => prev.filter((_, i) => i !== nextItemIdx));
      playTrack(nextTrack, currentQueueRef.current, true);
    } else {
      const baseList = currentQueueRef.current.length > 0 ? currentQueueRef.current : tracks;
      if (baseList.length === 0) return;

      if (isShuffle) {
        playTrack(baseList[Math.floor(Math.random() * baseList.length)], baseList, true);
      } else {
        const currentIndex = baseList.findIndex(t => t.id === activeTrack?.id);
        const isLast = currentIndex === baseList.length - 1;
        
        if (isLast && loopMode === 'none') {
          stopCurrentTrack();
          setIsPlaying(false);
          return;
        }
        
        const nextIndex = isLast ? 0 : currentIndex + 1;
        playTrack(baseList[nextIndex], baseList, true);
      }
    }
  }

  const playPrev = () => {
    const baseList = currentQueueRef.current.length > 0 ? currentQueueRef.current : tracks;
    if (baseList.length === 0) return;
    
    const currentIndex = baseList.findIndex(t => t.id === activeTrack?.id);
    const prevIndex = currentIndex <= 0 ? baseList.length - 1 : currentIndex - 1;
    playTrack(baseList[prevIndex], baseList, true); 
  }

  const addToQueue = (e: React.MouseEvent, track: Track) => {
    e.stopPropagation()
    if (!activeTrack) {
      playTrack(track, displayedTracks)
    } else {
      const newItem: QueueItem = { qid: Date.now(), track, pinned: false }
      setQueue(prev => [...prev, newItem])
    }
  }

  const moveQueueItem = (idx: number, dir: -1 | 1) => {
    const newIdx = idx + dir;
    if (newIdx < 0 || newIdx >= queue.length) return;
    const newQueue = [...queue];
    const temp = newQueue[idx];
    newQueue[idx] = newQueue[newIdx];
    newQueue[newIdx] = temp;
    setQueue(newQueue);
  }

  const toggleQueuePin = (qid: number) => {
    setQueue(prev => {
      const updated = prev.map(item => item.qid === qid ? { ...item, pinned: !item.pinned } : item)
      return updated.sort((a, b) => {
        if (a.pinned === b.pinned) return 0
        return a.pinned ? -1 : 1
      })
    })
  }

  const removeFromQueue = (qid: number) => {
    setQueue(prev => prev.filter(item => item.qid !== qid))
  }

  const toggleFavorite = (e: React.MouseEvent, id: string) => {
    e.stopPropagation()
    const newFavs = favorites.includes(id) ? favorites.filter(fav => fav !== id) : [...favorites, id]
    setFavorites(newFavs)
    uSet('music_favs', JSON.stringify(newFavs))
    pushMusicState('favorites', newFavs)
  }

  const handleSeek = (e: React.ChangeEvent<HTMLInputElement>) => {
    const time = Number(e.target.value)
    if (audioRef.current) audioRef.current.currentTime = time
    setCurrentTime(time)
  }

  const handleVolume = (e: React.ChangeEvent<HTMLInputElement>) => {
    const vol = Number(e.target.value)
    if (audioRef.current) audioRef.current.volume = vol
    setVolume(vol)
  }

  const formatTime = (time: number) => {
    if (isNaN(time)) return "0:00"
    const m = Math.floor(time / 60)
    const s = Math.floor(time % 60)
    return `${m}:${s < 10 ? '0' : ''}${s}`
  }

  const handleSortChange = (type: 'title' | 'plays' | 'date') => {
    setSortType(type)
    localStorage.setItem('music_sort_type', type)
    setIsSortOpen(false)
  }

  const handleSortDirChange = () => {
    const newDir = sortDirection === 'asc' ? 'desc' : 'asc'
    setSortDirection(newDir)
    localStorage.setItem('music_sort_dir', newDir)
  }

  const createPlaylist = (e: React.FormEvent) => {
    e.preventDefault()
    if (!newListName.trim()) return
    if (playlists[newListName.trim()]) { alert("Bu isimde bir liste zaten var!"); return }
    const newPlaylists = { ...playlists, [newListName.trim()]: [] }
    setPlaylists(newPlaylists)
    uSet('music_playlists', JSON.stringify(newPlaylists))
    pushPlaylist(newListName.trim(), [])
    setNewListName('')
  }

  const deletePlaylist = (e: React.MouseEvent, name: string) => {
    e.stopPropagation()
    if(!confirm(`"${name}" listesini silmek istediğine emin misin?`)) return
    const newPlaylists = { ...playlists }
    delete newPlaylists[name]
    setPlaylists(newPlaylists)
    uSet('music_playlists', JSON.stringify(newPlaylists))
    removePlaylistRemote(name)
    if (currentPlaylist === name) { setRightPanelMode('dash'); setCurrentPlaylist(null) }
  }

  const handleDropOnPlaylist = (e: React.DragEvent | any, listName: string) => {
    if(e.preventDefault) e.preventDefault()
    const trackId = e.dataTransfer ? e.dataTransfer.getData('trackId') : e.trackId
    if (!trackId) return
    const currentList = playlists[listName] || []
    if (!currentList.includes(trackId)) {
      const newList = [...currentList, trackId]
      const newPlaylists = { ...playlists, [listName]: newList }
      setPlaylists(newPlaylists)
      uSet('music_playlists', JSON.stringify(newPlaylists))
      pushPlaylist(listName, newList)
    }
  }

  const removeTrackFromPlaylist = (e: React.MouseEvent | any, trackId: string, listName: string) => {
    if(e.stopPropagation) e.stopPropagation()
    const currentList = playlists[listName] || []
    const newList = currentList.filter(id => id !== trackId)
    const newPlaylists = { ...playlists, [listName]: newList }
    setPlaylists(newPlaylists)
    uSet('music_playlists', JSON.stringify(newPlaylists))
    pushPlaylist(listName, newList)
  }

  const downloadTxt = async (filename: string, content: string) => {
    try {
      const savePath = await save({ defaultPath: filename, filters: [{ name: 'Metin Belgesi', extensions: ['txt'] }] });
      if (savePath) {
        await invoke('save_txt_file', { path: savePath, content: content });
        alert('✅ Dosya başarıyla oluşturuldu ve bilgisayarına kaydedildi!');
      }
    } catch (err) {
      console.error("Kaydetme Hatası:", err);
      alert('❌ Dosya kaydedilirken bir hata oluştu:\n' + err);
    }
  }

  const exportAllTracks = async () => {
    const sorted = [...tracks].sort((a,b) => a.title.localeCompare(b.title))
    let content = `TÜM MÜZİK ARŞİVİ\nOluşturulma Tarihi: ${new Date().toLocaleString('tr-TR')}\n-----------------------------------\n\n`
    if (sorted.length === 0) {
      content += "Arşivinizde henüz hiç şarkı bulunmuyor."
    } else {
      content += `Toplam Şarkı: ${sorted.length}\n\n` + sorted.map((t, i) => `${i + 1}. ${t.title} [${t.format}]`).join('\n')
    }
    await downloadTxt('Tum_Muzik_Arsivim.txt', content)
  }

  const exportPlaylist = async (e: React.MouseEvent, name: string) => {
    e.stopPropagation()
    const listTrackIds = playlists[name] || []
    const listTracks = tracks.filter(t => listTrackIds.includes(t.id)).sort((a,b) => a.title.localeCompare(b.title))
    let content = `ÇALMA LİSTESİ: ${name.toUpperCase()}\nOluşturulma Tarihi: ${new Date().toLocaleString('tr-TR')}\n-----------------------------------\n\n`
    if (listTracks.length === 0) {
      content += "Bu çalma listesi şu an boş."
    } else {
      content += `Toplam Şarkı: ${listTracks.length}\n\n` + listTracks.map((t, i) => `${i + 1}. ${t.title} [${t.format}]`).join('\n')
    }
    await downloadTxt(`Liste_${name.replace(/\s+/g, '_')}.txt`, content)
  }

  let displayedTracks = [...tracks]
  if (activeTab === 'Favoriler') displayedTracks = displayedTracks.filter(t => favorites.includes(t.id))
  if (searchQuery) displayedTracks = displayedTracks.filter(t => t.title.toLowerCase().includes(searchQuery.toLowerCase()))

  displayedTracks.sort((a, b) => {
    if (sortType === 'title') return sortDirection === 'asc' ? a.title.localeCompare(b.title) : b.title.localeCompare(a.title)
    else if (sortType === 'plays') return sortDirection === 'desc' ? (playCounts[b.id] || 0) - (playCounts[a.id] || 0) : (playCounts[a.id] || 0) - (playCounts[b.id] || 0)
    else return sortDirection === 'desc' ? b.modified_at - a.modified_at : a.modified_at - b.modified_at
  })

  const currentPlaylistTracks = currentPlaylist ? tracks.filter(t => playlists[currentPlaylist]?.includes(t.id)) : []
  let filteredQueueSearch = [...tracks]
  if (queueSearchQuery) filteredQueueSearch = filteredQueueSearch.filter(t => t.title.toLowerCase().includes(queueSearchQuery.toLowerCase()))

  return (
    <div className="flex h-full w-full flex-col md:flex-row relative">
      {isSortOpen && <div className="absolute inset-0 z-40" onClick={() => setIsSortOpen(false)}></div>}

      {/* SOL PANEL (KÜTÜPHANE) */}
      <div className="flex w-full shrink-0 flex-col border-r border-border bg-sidebar md:w-[520px] z-10">
        <div className="flex items-center justify-between px-5 pt-5 pb-2">
          <h1 className="flex items-center gap-2 text-xl font-bold tracking-tight">
            <ListMusic className="h-6 w-6 text-primary" /> Kütüphane
          </h1>
          <div className="flex gap-2">
            <button 
              onClick={() => { setRightPanelMode(prev => prev === 'dash' || prev === 'playlist_detail' || prev === 'playlist_add' ? 'player' : 'dash'); setCurrentPlaylist(null); }} 
              className={cn("flex items-center gap-2 px-3 py-1.5 rounded-lg text-sm font-medium transition-colors", rightPanelMode !== 'player' ? "bg-primary text-primary-foreground shadow-sm" : "bg-primary/10 text-primary hover:bg-primary hover:text-primary-foreground")}
            >
              <ListVideo className="h-4 w-4" /> {rightPanelMode !== 'player' ? "Oynatıcıya Dön" : "Listelerim"}
            </button>
            <button onClick={handleScanFolder} className="flex h-8 w-8 items-center justify-center rounded-lg bg-secondary text-foreground hover:bg-secondary/80 transition-colors" title="Klasör Seç">
              <FolderPlus className="h-4 w-4" />
            </button>
          </div>
        </div>
        
        <div className="flex gap-2 px-5 py-2">
          {['Tümü', 'Favoriler'].map(tab => (
            <button key={tab} onClick={() => setActiveTab(tab as any)} className={cn("px-4 py-1.5 rounded-full text-[13px] font-medium transition-colors", activeTab === tab ? "bg-primary text-primary-foreground" : "bg-secondary/50 text-muted-foreground hover:text-foreground hover:bg-secondary")}>
              {tab}
            </button>
          ))}
        </div>

        <div className="flex items-center gap-2 px-5 py-3 relative z-50">
          <div className="flex flex-1 items-center gap-2 rounded-xl border border-border bg-background px-3 py-2.5 focus-within:ring-1 focus-within:ring-primary/50 transition-all">
            <Search className="h-4 w-4 text-muted-foreground" />
            <input type="text" value={searchQuery} onChange={(e) => setSearchQuery(e.target.value)} placeholder="Şarkı ara..." className="w-full bg-transparent text-sm text-foreground focus:outline-none" />
          </div>
          
          <div className="relative shrink-0 flex items-center h-[46px]">
            <div className="flex items-center rounded-xl border border-border bg-background h-full transition-colors overflow-hidden px-2 relative w-32">
              <select 
                value={sortType} 
                onChange={(e) => handleSortChange(e.target.value as any)}
                className="w-full bg-transparent text-sm font-medium text-foreground outline-none appearance-none cursor-pointer z-10 pl-2"
              >
                <option value="title" className="bg-sidebar text-foreground">İsim</option>
                <option value="plays" className="bg-sidebar text-foreground">Dinlenme</option>
                <option value="date" className="bg-sidebar text-foreground">Tarih</option>
              </select>
              <ArrowDown className="h-3 w-3 absolute right-3 pointer-events-none text-muted-foreground z-0" />
            </div>
            <button onClick={handleSortDirChange} className="h-full px-3 text-muted-foreground hover:text-primary transition-colors bg-background border border-border border-l-0 rounded-r-xl ml-[-1px]" title="Yönü Değiştir">
              {sortDirection === 'desc' ? <ArrowDown className="h-4 w-4" /> : <ArrowUp className="h-4 w-4" />}
            </button>
          </div>
        </div>

        <div className="flex-1 overflow-y-auto px-3 pb-3 mt-1 relative z-0">
          {isLoading ? (
            <div className="text-center mt-10"><p className="text-sm font-medium text-primary animate-pulse">Arşiv taranıyor...</p></div>
          ) : displayedTracks.length === 0 ? (
            <div className="text-center mt-10"><p className="text-sm text-muted-foreground">Şarkı bulunamadı.</p></div>
          ) : (
            displayedTracks.map((track) => (
              <div 
                key={track.id} 
                draggable
                onDragStart={(e) => { e.dataTransfer.setData('trackId', track.id) }}
                onClick={() => playTrack(track, displayedTracks)}
                className={cn('group mb-1 flex w-full items-center gap-3 rounded-xl px-3 py-2.5 text-left transition-colors relative overflow-hidden cursor-pointer', activeTrack?.id === track.id ? 'bg-accent' : 'hover:bg-accent/40')}
              >
                <div className={cn('relative flex h-10 w-10 shrink-0 items-center justify-center rounded-lg shadow-sm overflow-hidden transition-colors', activeTrack?.id === track.id ? 'bg-primary text-primary-foreground' : 'bg-background border border-border text-muted-foreground group-hover:bg-primary/20 group-hover:text-primary group-hover:border-primary/50')}>
                  {activeTrack?.id === track.id ? (
                    isPlaying ? (
                      <div className="flex gap-0.5 h-3 items-end">
                        <div className="w-0.5 bg-primary-foreground h-full animate-[bounce_1s_infinite]"></div>
                        <div className="w-0.5 bg-primary-foreground h-2/3 animate-[bounce_1.2s_infinite]"></div>
                        <div className="w-0.5 bg-primary-foreground h-1/2 animate-[bounce_0.8s_infinite]"></div>
                      </div>
                    ) : <Pause className="h-4 w-4 fill-current" />
                  ) : (
                    <Play className="h-4 w-4 fill-current ml-0.5 opacity-50 group-hover:opacity-100 transition-opacity" />
                  )}
                </div>
                
                <div className="min-w-0 flex-1 pr-16 z-10 pointer-events-none">
                  <p className={cn('truncate text-[15px] font-semibold', activeTrack?.id === track.id ? 'text-primary' : 'text-foreground')}>{track.title}</p>
                  <div className="flex items-center gap-2 mt-0.5">
                    <p className="truncate text-[11px] text-muted-foreground font-mono bg-secondary/50 px-1.5 rounded">{track.format}</p>
                    {playCounts[track.id] > 0 && <p className="text-[10px] text-muted-foreground/60">{playCounts[track.id]} oynatma</p>}
                  </div>
                </div>
                
                <div className="absolute right-3 top-1/2 -translate-y-1/2 flex items-center bg-background/90 backdrop-blur shadow-sm p-1 rounded-lg opacity-0 group-hover:opacity-100 transition-opacity z-20 border border-border">
                  <button onClick={(e) => addToQueue(e, track)} className="p-1.5 transition-colors cursor-pointer text-muted-foreground hover:text-primary" title="Sıraya Ekle">
                    <ListPlus className="h-4 w-4" />
                  </button>
                  <button onClick={(e) => toggleFavorite(e, track.id)} className="p-1.5 transition-colors cursor-pointer" title="Favori">
                    <Heart className={cn("h-4 w-4", favorites.includes(track.id) ? "text-red-500" : "text-muted-foreground hover:text-red-500")} fill={favorites.includes(track.id) ? "currentColor" : "none"} />
                  </button>
                </div>
                {favorites.includes(track.id) && <Heart className="absolute right-4 top-1/2 -translate-y-1/2 h-3 w-3 text-red-500/50 group-hover:opacity-0 z-10 pointer-events-none" fill="currentColor" />}
              </div>
            ))
          )}
        </div>
      </div>

      <div className="flex min-h-0 flex-1 flex-col items-center justify-start bg-background relative overflow-hidden">
        {rightPanelMode === 'dash' ? (
          <div className="h-full w-full flex flex-col p-8 md:p-12 overflow-y-auto">
            <div className="max-w-4xl mx-auto w-full">
              <div className="flex flex-col md:flex-row md:items-end justify-between gap-6 mb-10 border-b border-border pb-6">
                <div>
                  <h2 className="text-3xl font-bold tracking-tight">Listelerim</h2>
                  <p className="text-muted-foreground mt-2">Sol menüden bir şarkıyı tutup kutuların üzerine sürükleyerek anında ekleyin.</p>
                </div>
                
                <button onClick={exportAllTracks} className="shrink-0 flex items-center gap-2 bg-secondary text-foreground px-4 py-2.5 rounded-xl hover:bg-secondary/80 transition-colors font-medium cursor-pointer shadow-sm">
                  <Download className="h-4 w-4" /> Arşivi TXT Çıkar

import { invoke } from '@tauri-apps/api/core'
import { open } from '@tauri-apps/plugin-dialog'

type Project = { name: string; path: string; ptype: string; }

export function ProjectsView() {
  const [rootFolders, setRootFolders] = useState<string[]>([])
  const [projects, setProjects] = useState<Project[]>([])
  const [searchQuery, setSearchQuery] = useState('')
  const [isLoading, setIsLoading] = useState(false)

  useEffect(() => {
    const saved = localStorage.getItem('ultimate_project_roots')
    if (saved) {
      const folders = JSON.parse(saved)
      setRootFolders(folders)
      scanAllRoots(folders)
    }
  }, [])

  const scanAllRoots = async (folders: string[]) => {
    setIsLoading(true)
    let allProjects: Project[] = []
    for (const folder of folders) {
      try {
        const res = await invoke<Project[]>('get_projects', { folderPath: folder })
        allProjects = [...allProjects, ...res]
      } catch (err) { console.error(err) }
    }
    setProjects(allProjects)
    setIsLoading(false)
  }

  const addRootFolder = async () => {
    try {
      const selected = await open({ directory: true, multiple: false })
      if (selected && typeof selected === 'string') {
        if (rootFolders.includes(selected)) return alert("Bu klasör zaten ekli!")
        const newFolders = [...rootFolders, selected]
        setRootFolders(newFolders)
        localStorage.setItem('ultimate_project_roots', JSON.stringify(newFolders))
        scanAllRoots(newFolders)
      }
    } catch (err) { console.error(err) }
  }

  const removeRootFolder = (folder: string) => {
    const newFolders = rootFolders.filter(f => f !== folder)
    setRootFolders(newFolders)
    localStorage.setItem('ultimate_project_roots', JSON.stringify(newFolders))
    scanAllRoots(newFolders)
  }

  const openInIde = async (path: string, ide: string) => {
    try {
      await invoke('open_in_ide', { path, ide })
    } catch (err) {
      alert("Hata: " + err + "\n\nNot: IDE'nin bilgisayarında kurulu ve 'Path' (Ortam Değişkenleri) ayarlarına ekli olduğundan emin ol.")
    }
  }

      <div className="flex w-full shrink-0 flex-col border-r border-border bg-sidebar md:w-[350px] z-10">

            <FolderPlus className="h-4 w-4" />
          </button>
        </div>
        
        <div className="flex-1 overflow-y-auto px-4 py-4 space-y-2">
          {rootFolders.length === 0 ? (
            <p className="text-sm text-muted-foreground text-center mt-4">Projelerinin bulunduğu bir ana klasör ekle (Örn: C:\Projelerim)</p>
          ) : (
            rootFolders.map((folder, idx) => (
              <div key={idx} className="flex items-center justify-between bg-background border border-border p-3 rounded-xl group hover:border-primary/50 transition-colors">
                <div className="flex items-center gap-2 truncate pr-2">
                  <FolderOpen className="h-4 w-4 text-blue-400 shrink-0" />
                  <span className="text-xs font-mono truncate" title={folder}>{folder}</span>
                </div>
                <button onClick={() => removeRootFolder(folder)} className="text-muted-foreground hover:text-red-500 opacity-0 group-hover:opacity-100 transition-opacity">
                  <Trash2 className="h-4 w-4" />
                </button>

use serde::Serialize;
use std::fs;
use std::io::Write;
use std::path::{Path, PathBuf};
use std::process::Command;
use tauri::path::BaseDirectory;
use tauri::Manager;

#[derive(Serialize, Clone)]
pub struct Track {
    id: String,
    title: String,
    format: String,
    path: String,
    modified_at: u64,
}

fn get_all_tracks(root: &Path, dir: &Path, tracks: &mut Vec<Track>) {
    let supported_exts = ["mp3", "m4a", "wav", "flac", "ogg", "aac", "wma", "mid", "midi"];
    if let Ok(entries) = fs::read_dir(dir) {
        // Deterministik sıra: dosya sistemi sırasına güvenmiyoruz,
        // böylece tarama her seferinde aynı listeyi üretir.
        let mut paths: Vec<PathBuf> = entries.flatten().map(|e| e.path()).collect();
        paths.sort();

        for path in paths {
            if path.is_dir() {
                get_all_tracks(root, &path, tracks);
            } else if path.is_file() {
                if let Some(ext) = path.extension().and_then(|e| e.to_str()) {
                    let ext_lower = ext.to_lowercase();
                    if supported_exts.contains(&ext_lower.as_str()) {
                        let title = path.file_stem().and_then(|n| n.to_str()).unwrap_or("Bilinmeyen Şarkı").to_string();
                        let modified_at = fs::metadata(&path).and_then(|m| m.modified()).ok().and_then(|t| t.duration_since(std::time::UNIX_EPOCH).ok()).map(|d| d.as_secs()).unwrap_or(0);

                        // KARARLI ID: taranan kök klasöre göre göreli yol (küçük harf, "/" ayraç).
                        // trk_1, trk_2... gibi sayaç tabanlı ID'ler her taramada dosya sistemine
                        // göre kayabildiği için favoriler/playlist'ler yanlış şarkıya işaret ediyordu.
                        let relative = path.strip_prefix(root).unwrap_or(&path);
                        let id = relative.to_string_lossy().replace('\\', "/").to_lowercase();

                        tracks.push(Track { id, title, format: ext_lower.to_uppercase(), path: path.to_string_lossy().into_owned(), modified_at });
                    }
                }
            }
        }
    }
}

#[tauri::command]
fn scan_music_folder(folder_path: &str) -> Result<Vec<Track>, String> {
    let path = Path::new(folder_path);
    if !path.exists() || !path.is_dir() { return Err("Klasör bulunamadı.".into()); }
    let mut tracks = Vec::new();
    get_all_tracks(path, &path, &mut tracks);
    Ok(tracks)
}

#[derive(Serialize, Clone)]
pub struct ProjectData {
    name: String,
    path: String,
    ptype: String,
}

#[tauri::command]
fn get_projects(folder_path: &str) -> Result<Vec<ProjectData>, String> {
    let path = Path::new(folder_path);
    let mut projects = Vec::new();

    if let Ok(entries) = fs::read_dir(path) {
        for entry in entries.flatten() {
            let p = entry.path();
            if p.is_dir() {
                let name = p.file_name().unwrap_or_default().to_string_lossy().to_string();
                let mut ptype = "Genel Klasör".to_string();

                if p.join("package.json").exists() { ptype = "Node.js / React".to_string(); }
                else if p.join("build.gradle").exists() || p.join("build.gradle.kts").exists() { ptype = "Android Studio".to_string(); }
                else if p.join("CMakeLists.txt").exists() { ptype = "C / C++".to_string(); }
                else if p.join("pom.xml").exists() { ptype = "Java".to_string(); }
                else if p.join("main.py").exists() { ptype = "Python".to_string(); }
                else {
                    if let Ok(sub_entries) = fs::read_dir(&p) {
                        for sub in sub_entries.flatten() {
                            if let Some(ext) = sub.path().extension() {
                                if ext == "sln" {
                                    ptype = "Visual Studio (C#)".to_string();
                                    break;
                                }
                            }
                        }
                    }
                }

                projects.push(ProjectData { name, path: p.to_string_lossy().to_string(), ptype });
            }
        }
    }
    projects.sort_by(|a, b| a.name.to_lowercase().cmp(&b.name.to_lowercase()));
    Ok(projects)
}

#[tauri::command]
fn open_in_ide(path: &str, ide: &str) -> Result<(), String> {
    let is_win = cfg!(target_os = "windows");

    match ide {
        "vscode" => {
            if is_win { Command::new("cmd").args(["/C", "code", path]).spawn().map_err(|e| e.to_string())?; } 
            else { Command::new("code").arg(path).spawn().map_err(|e| e.to_string())?; }
        }
        "eclipse" => {
            if is_win { Command::new("cmd").args(["/C", "eclipse", path]).spawn().map_err(|e| e.to_string())?; } 
            else { Command::new("eclipse").arg(path).spawn().map_err(|e| e.to_string())?; }
        }
        "android_studio" => {
            if is_win { Command::new("cmd").args(["/C", "studio", path]).spawn().map_err(|e| e.to_string())?; } 
            else { Command::new("studio").arg(path).spawn().map_err(|e| e.to_string())?; }
        }
        "intellij" => {
            if is_win { Command::new("cmd").args(["/C", "idea", path]).spawn().map_err(|e| e.to_string())?; } 
            else { Command::new("idea").arg(path).spawn().map_err(|e| e.to_string())?; }
        }
        "visual_studio" => {
            let mut sln_path = String::new();
            if let Ok(entries) = fs::read_dir(Path::new(path)) {
                for entry in entries.flatten() {
                    if entry.path().extension().and_then(|e| e.to_str()) == Some("sln") {
                        sln_path = entry.path().to_string_lossy().to_string();
                        break;
                    }
                }
            }
            
            let target = if !sln_path.is_empty() { sln_path } else { path.to_string() };
            
            if is_win { Command::new("cmd").args(["/C", "start", "", &target]).spawn().map_err(|e| e.to_string())?; } 
            else { Command::new("open").arg(&target).spawn().map_err(|e| e.to_string())?; }
        }
        "explorer" => {
            if is_win { Command::new("explorer").arg(path).spawn().map_err(|e| e.to_string())?; } 
            else { Command::new("open").arg(path).spawn().map_err(|e| e.to_string())?; }
        }
        _ => return Err("Geçersiz IDE".to_string()),
    }

    Ok(())
}

// GÖMÜLÜ KAYNAK: resources/ klasöründeki dosyayı her iki modda da (dev + paketlenmiş) bulur.
// Aday sırası:
//   1) $RESOURCE/<dosya>              -> bundle.resources map/modu ile gömülmüş hali
//   2) $RESOURCE/resources/<dosya>    -> liste tanımda yapı korunarak kopyalanan hali
//   3) CARGO_MANIFEST_DIR/resources/  -> tauri dev'de doğrudan kaynak klasörden (build kopyası olmadan da çalışır)
fn resolve_bundled_resource(app_handle: &tauri::AppHandle, file_name: &str) -> Result<PathBuf, String> {
    let mut candidates: Vec<PathBuf> = Vec::new();

    if let Ok(resource_dir) = app_handle.path().resource_dir() {
        candidates.push(resource_dir.join(file_name));
        candidates.push(resource_dir.join("resources").join(file_name));
    }

    if let Ok(resolved) = app_handle.path().resolve(file_name, BaseDirectory::Resource) {
        candidates.push(resolved);
    }

    candidates.push(
        PathBuf::from(env!("CARGO_MANIFEST_DIR"))
            .join("resources")
            .join(file_name),
    );

    candidates
        .into_iter()
        .find(|path| path.exists())
        .ok_or_else(|| {
            format!(
                "Gömülü kaynak bulunamadı: {}. Dosyayı src-tauri/resources/ klasörüne ekleyin.",
                file_name
            )
        })
}

#[tauri::command]
fn install_rainmeter_widgets(app_handle: tauri::AppHandle) -> Result<String, String> {
    let is_win = cfg!(target_os = "windows");
    if !is_win { return Err("Bu özellik sadece Windows'ta geçerlidir.".into()); }

    let rainmeter_path = Path::new("C:\\Program Files\\Rainmeter\\Rainmeter.exe");
    let skin_installer_path = Path::new("C:\\Program Files\\Rainmeter\\SkinInstaller.exe");

    // Uygulama içine gömdüğümüz resources yollarını Tauri v2 API'si ile alıyoruz
    let bundled_rainmeter_exe = resolve_bundled_resource(&app_handle, "Rainmeter-4.5.exe")?;
    let bundled_skin = resolve_bundled_resource(&app_handle, "Ultimate.rmskin")?;

    // 1. AŞAMA: Rainmeter kurulu mu diye bak
    if !rainmeter_path.exists() {
        // Kurulu değilse, kendi gömdüğümüz Rainmeter Setup'ını başlat
        Command::new("cmd")
            .arg("/C")
            .arg(&bundled_rainmeter_exe)
            .spawn()
            .map_err(|e| format!("Rainmeter kurulumu başlatılamadı: {}", e))?;

        return Ok("RAINMETER_SETUP_STARTED".into());
    }

    // 2. AŞAMA: Rainmeter kuruluysa, bizim .rmskin paketimizi otomatik kur!
    if skin_installer_path.exists() {
        Command::new(skin_installer_path)
            .arg(&bundled_skin)
            .spawn()
            .map_err(|e| format!("Tema kurulamadı: {}", e))?;

        // Temayı anında ekranda göster
        let _ = Command::new(rainmeter_path)
            .args(["!ActivateConfig", "Ultimate", "Ultimate.ini"])
            .spawn();

        return Ok("WIDGET_INSTALLED".into());
    }

    Err("Bilinmeyen bir hata oluştu.".into())
}

#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_opener::init())
        .plugin(tauri_plugin_fs::init()) 
        .plugin(tauri_plugin_dialog::init()) 
        .invoke_handler(tauri::generate_handler![scan_music_folder, read_audio_file, save_txt_file, get_projects, open_in_ide, install_rainmeter_widgets]) 
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}

# resources/ — Gömülü Kurulum Dosyaları

Bu klasör, `tauri build` ile üretim (`.exe`/`.msi`) yaparken uygulamanın **içine gömülür**.

## Beklenen dosyalar

| Dosya | Ne işe yarar |
|---|---|
| `Rainmeter-4.5.exe` | Kullanıcıda Rainmeter yoksa sessizce kurmak için resmi kurulum dosyası |
| `Ultimate.rmskin` | Sizin widget'larınızın (Günün Olayı vb.) paketlenmiş hali |

## Nereden alınır

1. **Rainmeter-4.5.exe** → <https://www.rainmeter.net> sayfasından indirilir, adı tam olarak `Rainmeter-4.5.exe` olacak şekilde bu klasöre kopyalanır.
2. **Ultimate.rmskin** → Rainmeter içinde sağ alttaki damla ikonuna tıklayıp
   "Paket Oluştur / Create .rmskin" diyerek mevcut temanız tek tıkla paketlenir.
   Paket adını `Ultimate.rmskin` yapıp bu klasöre koyun.

## Notlar (önemli)

- `tauri.conf.json > bundle > resources` şu anda `resources/**/*` glob'u ile tanımlı.
  Klasörde eşleşen **en az bir** dosya yoksa `tauri dev`/`tauri build`
  hata verir. Klasör şimdilik `.gitkeep` sayesinde doludur; gerçek dosyaları
  eklediğinizde hiçbir yapılandırma değişikliği gerekmez.
- Kod tarafında `src-tauri/src/lib.rs` içindeki `resolve_bundled_resource`
  hem development hem paketlenmiş kurulumda dosyaları bulur:
  1. `$RESOURCE/<dosya>`
  2. `$RESOURCE/resources/<dosya>`
  3. `src-tauri/resources/<dosya>` (geliştirme modu)
- Komut Rust tarafında: `install_rainmeter_widgets` (invoke_handler'a kayıtlı).
  React tarafı: `src/components/SetupWizard.tsx` → `App.tsx` içinde render edilir.

-- 7) KİMLİK DOĞRULAMA (Auth) GEÇİŞİ
--    ÖNEMLİ: Bu bölümü çalıştırmadan önce Dashboard ->
--    Authentication -> Users ekranından bir kullanıcı oluştur
--    (email + şifre, "Auto Confirm" işaretli olsun).
--    Aksi halde bu bölüm uyarı verip durur.
-- ============================================================

-- Her tabloya sahip kolonu ekle (varsayılan: giriş yapan kullanıcı)
alter table public.notes add column if not exists user_id uuid default auth.uid();
alter table public.calendar_events add column if not exists user_id uuid default auth.uid();
alter table public.playlists add column if not exists user_id uuid default auth.uid();
alter table public.music_state add column if not exists user_id uuid default auth.uid();

do $$
declare
  owner_id uuid;
begin
  select id into owner_id from auth.users order by created_at limit 1;

  if owner_id is null then
    raise exception 'Once Authentication -> Users bolumunden bir kullanici olustur, sonra bu SQL''i tekrar calistir.';
  end if;

  -- Mevcut (sahipsiz) satırları bu kullanıcıya bağla
  update public.notes set user_id = owner_id where user_id is null;
  update public.calendar_events set user_id = owner_id where user_id is null;
  update public.playlists set user_id = owner_id where user_id is null;
  update public.music_state set user_id = owner_id where user_id is null;

  alter table public.notes alter column user_id set not null;
  alter table public.calendar_events alter column user_id set not null;
  alter table public.playlists alter column user_id set not null;
  alter table public.music_state alter column user_id set not null;

  -- playlists / music_state anahtarları kullanıcıya göre bileşik olmalı
  alter table public.playlists drop constraint if exists playlists_pkey;
  alter table public.playlists add constraint playlists_pkey primary key (user_id, name);
  alter table public.music_state drop constraint if exists music_state_pkey;
  alter table public.music_state add constraint music_state_pkey primary key (user_id, key);
end $$;

-- 9) NOT RESİMLERİ (Supabase Storage)
--    Notlara eklenen resimler artık base64 olarak veritabanına
--    gömülmez; bu bucket'a yüklenir ve nota yalnızca genel URL
--    yazılır. Böylece DB şişmez ve resimler diğer cihazlarda da görünür.
--
--    Bucket: note-images (public = true)
--    Yazma/silme: yalnızca kendi klasörü -> <user_id>/dosya.png
--    Okuma: public bucket olduğu için bağlantıyı bilen görüntüleyebilir
--    (kişisel kullanım için pratik; gizlilik istersen bucket'ı private
--     yapıp imzalı URL üretimine geçebiliriz).
-- ============================================================

insert into storage.buckets (id, name, public)
values ('note-images', 'note-images', true)
on conflict (id) do update set public = true;

drop policy if exists note_images_insert_own on storage.objects;
create policy note_images_insert_own on storage.objects
  for insert to authenticated
  with check (
    bucket_id = 'note-images'
    and (storage.foldername(name))[1] = auth.uid()::text
  );

drop policy if exists note_images_update_own on storage.objects;
create policy note_images_update_own on storage.objects
  for update to authenticated
  using (
    bucket_id = 'note-images'
    and (storage.foldername(name))[1] = auth.uid()::text
  )
  with check (
    bucket_id = 'note-images'
    and (storage.foldername(name))[1] = auth.uid()::text
  );

drop policy if exists note_images_delete_own on storage.objects;
create policy note_images_delete_own on storage.objects
  for delete to authenticated
  using (
    bucket_id = 'note-images'
    and (storage.foldername(name))[1] = auth.uid()::text
  );
